# Design reference

Created with the built-in image-generation tool as a `ui-mockup`. Saved reference: `workspace-concept.png`.

## Prompt

Design a complete high-fidelity desktop screenshot for VendorRisk Triage, a polished third-party vendor security review tool for a portfolio demo. Use a calm enterprise style with Geist/Inter, white surfaces, a cool grey canvas, slate text, teal actions, restrained borders and roughly 10px radii. Include a 240px vendor sidebar, Northwind/Apex/Sterling initials and sector labels, a top bar with mode/GitHub/theme controls, the Northwind workspace title and Export report/Run triage actions, a manual/AI time estimate, four document cards and an upload strip. Below, include Assessment and Follow-up questions tabs, a 68/High circular gauge, executive summary, seven domain bars and a sortable/filterable findings table. Findings cover optional privileged MFA, breach notification, offshore support disclosure, access review exceptions, missing penetration test evidence and unverified recovery testing. Use severity colors only for risk signals. Keep the entire compact screen legible, practical to implement as native components, without photos, marketing sections or invented navigation.

## Implementation corrections

The image supplies layout and visual direction. The brief and real seeded data govern wording, domains, scores, word counts, review targets and evidence. The final app corrects the concept's inaccurate domain labels, invented document references and notification wording. Contrast-safe severity labels, removable review documents and explicit sample/coverage labels support the required workflow.
